WorldX AI — المرحلة 2 (واجهة + نقطة ربط Gemini)

محتويات:
- index.html: الواجهة.
- api/chat.js: وسيط API آمن نسبيًا، يقرأ المفتاح من متغير البيئة ولا يكشفه للمتصفح.
- api/health.js: فحص الإعدادات.
- manifest.json و sw.js: أساسيات PWA.
- vercel.json: إعدادات نشر أولية.

مهم جدًا:
هذه ملفات مشروع تحتاج نشرًا على استضافة تدعم Serverless Functions مثل Vercel. لم يتم نشر الموقع على الإنترنت من هنا، ولم يتم إنشاء مفتاح API لك.
لا تضع المفتاح داخل index.html أو في أي ملف تنشره للعامة.

الخطوات التالية على الهاتف:
1) أنشئ/سجّل الدخول إلى Google AI Studio عبر المتصفح، وأنشئ API key وفق التعليمات الرسمية.
2) أنشئ مشروعًا جديدًا على منصة استضافة تدعم وظائف Node.js serverless، وارفع ملفات هذا المجلد مع الحفاظ على مجلد api.
3) في إعدادات المشروع > Environment Variables أضف:
   GEMINI_API_KEY = (المفتاح الخاص بك)
   اختياريًا GEMINI_MODEL = gemini-2.5-flash
4) أعد النشر، ثم افتح رابط الموقع واضغط "اختبار اتصال AI".
5) بعد عمل المحادثة نضيف حفظ المحادثات، توليد الصور، ثم ربط مزود فيديو منفصل.

تنبيه التكلفة:
توفر Gemini API حصصًا مجانية لبعض النماذج وفق الحساب والمنطقة والسياسات الحالية، لكنها ليست غير محدودة وقد تتغير. لا تضع بيانات شخصية حساسة في النسخة التجريبية.
إنشاء الفيديو ليس مفعّلًا في هذا المشروع، ويحتاج مزودًا يدعم توليد الفيديو وقد تكون له تكلفة.
واجهة اختيار اللغة مترجمة جزئيًا فقط؛ ردود النموذج متعددة اللغات وليست كل نصوص الواجهة مترجمة بالكامل حتى الآن.

إذا لم تكن تعرف رفع الملفات، أرسل لي لقطة شاشة للصفحة التي وصلت إليها وسأرشدك خطوة بخطوة.
